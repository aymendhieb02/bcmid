# Public report copy

`BCMID_Technical_Report_Public.pdf` is a sanitized copy of the completed local technical report. The original file was preserved outside this publishing repository.

For public sharing, the copy replaces real source identifiers in the RAG ablation table with Passage A/B/C, removes the source-labeled chart, and removes the example ultrasound, its visible patient label, and the related image-specific result paragraph. The report’s aggregate discussion and methods remain. No report passages or raw image files were added to the repository.
