# Final notebook

[`BCMID_Final_Project.ipynb`](BCMID_Final_Project.ipynb) is the final Kaggle notebook for the BCMID project. It walks through dataset auditing, patient-level splits, report extraction and structuring, E5 embeddings and Chroma retrieval, image feature search, generation and citation checks, evaluation, the multi-agent design, and exploratory XAI.

The GitHub copy has saved outputs removed and uses synthetic labels in its small in-notebook fixtures. The notebook expects the BCMID dataset and model assets to be available in the Kaggle input environment; those large or sensitive assets are not included here.
